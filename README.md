# Paradise Nursery Shopping Application

## Features
- Browse a wide variety of beautiful houseplants.
- View detailed information and pricing for each plant.
- Add plants to your shopping cart.
- Manage cart items (update quantity, remove items).

## Installation Instructions
1. Clone the repository.
2. Run `npm install` to install all dependencies.

## Usage Examples
Run `npm start` to launch the application locally. Navigate through the site to explore plants and use the cart functionalities.
